Differentiable Catmull-Clark

This project turns Catmull-Clark subdivision into a differentiable layer and uses it to fit a coarse control cage so that its subdivided surface matches a target mesh.

Impact & Deliverables

  • Catmull-Clark subdivision as a differentiable operator for inverse geometry problems
  • Sample-based matching with symmetric Chamfer distance for topology-agnostic fitting
  • Regularizers: Laplacian smoothing, edge-length preservation, anchor-to-init, point-to-plane
  • Realtime browser demo that runs end-to-end optimization with TensorFlow.js autodiff

Tech Stack

PyTorch TensorFlow.js Geometry Processing Differentiable Graphics Mathematical Optimization
