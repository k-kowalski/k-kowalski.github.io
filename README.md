# Krzysztof Kowalski - Personal Website

Static personal website showcasing rendering, geometry processing, and real-time graphics work.

**Technologies:** HTML, CSS, JavaScript (vanilla)

## Local Development

Simply open `index.html` in your browser. No build step required.

## Deployment

Hosted on GitHub Pages. Any push to the `main` branch automatically deploys.

## Adding Screenshots

To replace placeholder screenshots:

1. Add image files to `assets/screenshots/`
2. Replace the `.screenshot-placeholder` div with:
   ```html
   <div class="screenshot-container">
     <img src="assets/screenshots/your-image.png" alt="Description">
   </div>
   ```

Recommended: 16:9 aspect ratio, 1280px+ width, WebP or PNG format.
